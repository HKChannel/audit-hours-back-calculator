# Audit Hours-Back Calculator

A single-page app in one file (`index.html`) with no dependencies. It's the companion tool for an edition of the LinkedIn newsletter **AI in Finance, Done Right**: **"You Don't Need a $1 Billion AI Budget to Modernize Audit—Look at What a 70-Person Firm Did Inside Excel"**.

## Features
- **Tab 1, Hours back:** Enter your engagements a year, average hours per engagement, staff cost, and the hours spent on four workflows (PDF extraction, invoice-to-ledger matching, footing and math checks, draft version compare). Savings presets come from vendor-published customer stories and are discounted by a realization slider (default 50%). See hours back per engagement and per year, the value at cost, and how many more engagements that capacity could cover without hiring.
- **Tab 2, Tool due diligence:** Six questions to ask before buying any audit AI tool. You get a readiness dial, the biggest gaps and a rollout plan you can copy.

The demo figures are made up. Everything runs in the browser and nothing is uploaded.
